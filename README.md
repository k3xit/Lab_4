# Поморцев Аким КМБ-1 Лабораторная №4

# Задание 1

## Задача 1

### Текст задачи

Дерево содержит строки. Добавить к каждой строке заданный символ в конец.

### Алгоритм решения
Пользователь вводит количество элементов дерева, проверяем на правильность ввода, 
при ошибке выводим сообщение и повторяем ввод. С помощью функции buildTree генерируем случайные строки 
и заполняем бинарное дерево. Выводим начальное дерево в трёх форматах: прямой обход, отсортированный вид, 
визуализация структуры. Пользователь вводит символ для добавления в конец строк, проверяем на 
правильность (не пустая строка, один символ), при ошибке выводим сообщение и повторяем ввод. 
С помощью функции mapTree проходим по всем узлам дерева и к каждой строке добавляем введённый символ 
через конкатенацию. Выводим итоговое дерево в трёх форматах на экран.

# Задание 2

## Задача 1

### Текст задачи

Сформировать список из четных элементов дерева.

### Алгоритм решения

Пользователь вводит количество элементов дерева, проверяем на правильность ввода, 
при ошибке выводим сообщение и повторяем ввод. С помощью функции buildIntTree генерируем 
случайные целые числа от 1 до 100 и заполняем бинарное дерево поиска. Выводим дерево в двух 
форматах: отсортированный вид и визуализация структуры. С помощью рекурсивной функции collectEven 
проходим по всем узлам дерева, проверяем каждый элемент на чётность через оператор остатка от деления, 
если элемент чётный — добавляем его в список, иначе пропускаем. Выводим полученный список чётных 
элементов на экран.
